# ViralCraft Studio Website Template

This is the launch-ready website template included in ShortForm Studio Kit.

## Best for

- UGC agencies
- AI video studios
- Creator growth agencies
- Short-form content operators
- Founder content services
- Content repurposing freelancers

## What to customize

1. Replace `ViralCraft` with your agency name.
2. Replace the hero headline with your offer.
3. Replace campaign examples with your own case studies or demo projects.
4. Update package names, prices, and deliverables.
5. Connect the contact form to Lemon Squeezy, Tally, Typeform, Basin, or your backend.
6. Upload this folder to Netlify, Vercel, Cloudflare Pages, GitHub Pages, or any static hosting provider.

## Files

- `index.html`: complete one-page agency website
- `services.html`: service details
- `case-study.html`: case study library
- `case-harbor-coffee.html`: demo case for local brands
- `case-glowbar.html`: demo case for beauty/UGC
- `case-novaclips.html`: demo case for AI video studios
- `blog.html`: static blog index
- `blog-detail.html`: article detail page
- `pricing.html`: package comparison
- `about.html`: method and team page
- `contact.html`: inquiry page
- `style-guide.html`: colors, typography, and components
- `404.html`: error page
- `styles.css`: responsive visual system
- `script.js`: FAQ toggle and demo form behavior
